概覽

這份政策適用於 timoji 1.7.0 與本隱私權及支援網站。timoji 是親子一起使用、陪孩子看見時間與安排日常活動的視覺計時工具，由台灣的 Chiang Chien Chu（Studio Kí.）營運。

使用 timoji 不需要建立 App 帳號。活動與計時資料儲存在你的裝置上，不會上傳至我們營運的伺服器。若你選擇寄信給我們，我們只使用你提供的資料回覆問題。

處理的資料

活動名稱、選取的照片與裁切設定、最愛、排序、儲存的日常流程、計時進度與設定，均在裝置上處理。近期活動時間與完成紀錄用於回復計時及避免重複提醒。本機隨機 ID 用來識別活動與計時，不是廣告或跨 App 追蹤識別碼。

系統照片選取器只提供你選取的圖片。選擇「拍照」時才會要求相機權限。匯入圖片會縮小並重新編碼為活動貼紙。照片及相機功能皆為選用，內建貼紙不需使用這些權限。timoji 不要求位置、聯絡人、麥克風或完整照片圖庫的存取權限。

在支援的裝置與系統上，你可以使用 Apple 的 Image Playground（包含 Genmoji）製作活動圖像。生成流程由 Apple 依其隱私條款提供，可能使用裝置端模型、Apple 服務，或你在系統介面選用的延伸功能。timoji 只接收你確認採用的圖片並儲存在本機，不會將活動資料庫傳送至開發者的圖片生成服務。此功能為選用，照片與內建貼紙仍可使用。請參閱 Apple Intelligence 與隱私權。

目前版本沒有廣告、追蹤、第三方分析或當機回報 SDK。我們不出售個人資料、不為定向廣告分享資料，也不建立廣告用戶資料。自願寄來的信件與網站主機資料處理方式，請見下方說明。

資料儲存方式

活動、照片、日常流程與計時設定儲存在本機 App 空間。我們沒有接收這份資料庫的伺服器，timoji 也沒有獨立雲端帳號或跨 App 同步服務。裁切後的貼紙副本另存於裝置上的共用 App Group 空間，供即時動態延伸功能顯示。主畫面小工具也會從同一個空間讀取一份小快照（貼紙與日常流程名稱、目前計時狀態），只存在這台裝置。

timoji Plus 的活動紀錄會記下完成的活動（活動名稱、開始與結束時間、專注分鐘數）。活動時間紀錄儲存在這台裝置；若開啟 iCloud 備份，也會一併備份。timoji 不會收集。在「管理紀錄」裡，你可以把紀錄匯出成試算表（CSV）或 timoji 備份檔、匯入備份、清除紀錄，或關閉紀錄；匯出的檔案只會存到你選擇的位置。

裝置或 iCloud 備份可能依你的 Apple 設定包含 App 資料；這些系統備份與 timoji 本機儲存不同。我們無法存取、回復或刪除你的本機資料庫或 Apple 備份。你可以透過 Apple 裝置與帳號設定管理備份。

購買

Apple 透過 App Store 處理 timoji Plus 的付款與回復購買項目。timoji 在裝置上核對已驗證的 StoreKit 交易，以解鎖已購買的功能。

我們不會取得你的付款卡資料或 Apple 帳號密碼。Apple 依其 隱私權政策 處理購買資料。

兒童隱私

親子可以一起用 timoji 看見並理解時間。免費計時器不需要帳號、姓名、照片、年齡或線上個人資料。購買、自訂照片與外部連結，應由家長或照顧者協助管理。

本 App 沒有家長同意驗證系統。請勿透過信件寄送孩子的照片或不必要的個人資料。若你認為孩子曾寄來個人資料，家長或照顧者可以聯絡我們要求刪除；必要的資料保留仍依適用規定處理。

第三方服務

App 使用 Apple 系統服務處理購買、選用的照片選取與相機、以及選用的本機通知；若開啟「時間到提醒」，也會透過 Apple 的 AlarmKit 在裝置上排定鬧鐘。App 沒有註冊開發者營運的遠端推播服務。裝置可能依你的系統設定與 Apple 分享診斷資料。

網站由 GitHub Pages 託管。GitHub 會為安全目的記錄訪客 IP 位址，即使訪客未登入也一樣。請參閱 GitHub 主機說明 與 隱私權聲明。網站本身沒有加入分析、追蹤程式、Cookie、表單或外部字體。

外部連結會開啟適用其各自政策的服務。開啟連結可能向該服務揭露 IP 位址等連線資訊。信件處理方式請見下一節。

支援信件

若你寄信到 heytimoji@gmail.com，Chiang Chien Chu 會透過 Gmail（Google） 收信及回覆。我們使用你的信箱、訊息及自願提供的內容回答問題、排除問題，或回應回饋及隱私權要求。

除了 Google 的 Gmail 郵件服務，支援信件不會轉交 CRM、客服平台、分析或其他第三方服務，也不會用於行銷或用戶分析。

寄信是自願的，不影響你使用 timoji。若缺少相關資訊，我們可能無法完整回答問題。請避免寄送不必要的敏感資料。

資料保留

本機 App 資料會保留到你修改、移除，或刪除 App 及其資料。刪除活動也會移除已儲存日常流程中對應的步驟；正在進行的計時會保留活動副本，直到這次計時結束。Apple 備份可能依設定保留舊副本。

一般已結案的支援信件會在問題處理完成後保留一年，再予以刪除。法律義務、付款爭議、安全事件或其他必要原因可能需要保留更久。Gmail（Google） 可能依其服務行為及設定保留已刪除訊息或備份。GitHub 則依其政策處理主機記錄。

你的權利

依適用法律，你可能有權要求存取、更正、刪除、取得資料副本、限制或反對處理。若處理依據是同意，你可能有權撤回同意，也可以向相關隱私權主管機關提出問題。

若要求涉及你寄給我們的資料，請來信 heytimoji@gmail.com。我們可能需要足夠資訊確認及回應要求。我們無法存取僅在你裝置上的資料；請使用 App 操作或刪除 App 及其資料。Apple、Google 或 GitHub 獨立持有的資料，請向各服務提出要求。

國際使用者

timoji 由台灣營運。若你從其他國家聯絡我們，訊息將透過 Gmail（Google），由我們在台灣處理。Apple、Google 及 GitHub 可能依其政策在你所在國家以外處理服務資料。

不同地區的隱私權要求可能不同。對你的資料或本政策有問題，請聯絡我們，我們會依適用規定處理。

政策更新

若 App 資料處理方式或網站有變更，我們會更新本政策及更新日期；如適用規定要求額外通知，我們也會提供。
